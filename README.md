# MakeReal

> Build Build Build!

MakeReal helps people turn an idea into a real next step using the resources they already have.

## MVP

The first version intentionally focuses on one loop:

```text
Idea
  ↓
Resources
  ↓
First Plan
  ↓
Action
  ↓
Learn
  ↓
Next Action
```

The current prototype is a small client-side application. It has no database and no AI dependency yet. That is intentional: first prove that a person can move through the core loop.

## Run

No build step is required. Open `index.html` in a browser, or serve the directory with any static HTTP server.

## Next

Once the loop is tested with real users, add persistence and then AI-assisted clarification, planning, and reflection without changing the core product loop.
